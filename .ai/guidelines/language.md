# Language

- Everything written to this repository MUST be in English: code, identifiers (variables, functions, classes, files, folders, routes, keys), comments, docblocks, UI text, validation and error messages, tests, migrations, documentation, `.ai/` guidelines and skills, commit messages, branch names, and PR titles and descriptions.
- This applies even when the user writes to you in another language. Reply to the user in their language in chat; write to the repository in English only.
